# 🔬 Research

## 📄 Sentiment-Aware Matrix Factorization for Enhanced Recommendation Systems

**First Author · IEEE DataSciMI 2026**

<a href="https://doi.org/10.1109/DataSciMI67380.2026.11523851">
<img src="https://img.shields.io/badge/DOI-10.1109%2FDataSciMI67380.2026.11523851-00629B?style=for-the-badge&logo=ieee&logoColor=white"/>
</a>

I developed a **Sentiment-Aware Matrix Factorization (SAMF)** approach that incorporates TF-IDF-derived user sentiment similarity into the matrix factorization objective to improve recommendation performance under sparse and cold-start conditions.

### 📊 Key Results

| Metric                 |            SAMF | LFM Baseline |
| :--------------------- | --------------: | -----------: |
| Test MAE               |      **0.6415** |       0.8069 |
| Cold-Start MAE         |      **0.7241** |       0.8912 |
| Test MAE Improvement   | **20.5% lower** |            — |
| Cold-Start Improvement | **18.8% lower** |            — |

### 🧪 Evaluation

* 📌 Amazon Movies & TV 5-core dataset
* 📌 Classical Matrix Factorization baseline
* 📌 NeuralMF comparison
* 📌 MAE evaluation
* 📌 Precision@K / Recall@K / F1@K
* 📌 NDCG@K / Hit Rate@K
* 📌 Cold-start vs. warm-start analysis
* 📌 Convergence analysis
* 📌 Seven-setting sensitivity analysis of the sentiment regularization parameter β
* 📌 Error and ranking-quality analysis

> **Research principle:** A model is only as good as the way you evaluate it.

📖 **[Read the IEEE Paper →](https://doi.org/10.1109/DataSciMI67380.2026.11523851)**
